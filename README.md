# Varma Visuals — Portfolio

A clean, single-page portfolio for **Megavarman**, Freelance Video Editor.
Built with **React + Vite + Tailwind CSS**.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
npm run preview  # preview the build
```

## Edit your content

Almost everything lives in **`src/data.js`** — brand name, tagline, services,
skills/tools, packages, portfolio videos, and contact details. Change it there
and the whole site updates.

## Add your photo

Drop a photo named **`profile.jpg`** into the **`public/`** folder. It appears
automatically in the hero. Until then, a placeholder is shown.

## Portfolio videos

Paste Dropbox share links into the `urls` arrays in `src/data.js`. The usual
`?...&dl=0` tail is converted automatically to a direct, streamable link, so
clips play right on the page. A card with an empty `urls: []` shows a tasteful
"Coming soon" state.

## Contact form

The form opens the visitor's email app pre-filled to your address (`mailto`).
No backend or API keys required.
